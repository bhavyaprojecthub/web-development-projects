🌟 Ratan Tata Motivational Poster
A simple motivational poster webpage built using HTML and CSS. The project displays an inspirational quote by Ratan Tata with a clean, centered poster design inspired by classic motivational posters.

📌 Features
Responsive poster layout
Black background with white text
Custom image with a white border
Google Fonts integration using Libre Baskerville
Center-aligned content
Clean and minimal design
🛠️ Technologies Used
HTML5
CSS3
Google Fonts (Libre Baskerville)
📂 Project Structure
project-folder
│
├── index.html
├── style.css
│
└── assets
    └── images
        └── ratan_tata.jpg


💬 Quote
"You cannot go through life and let things happen to you. You have to make things happen."

🚀 How to Run
Clone the repository.
Open the project folder.
Open index.html in your browser.
