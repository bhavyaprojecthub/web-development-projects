# 🎬 My Favorite Shows
A simple HTML webpage showcasing my top 3 favorite shows of all time.

## 📌 About
This project is a basic HTML exercise that displays a list of my favorite shows along with a short description of each one.

## 🏆 Top 3 Shows
1. **Oggy and the Cockroaches**
   * My favorite cartoon series.

2. **All of Us Are Dead**
   * A thrilling zombie survival drama.

3. **Kaiju No. 8**
   * One of my favorite anime series.
