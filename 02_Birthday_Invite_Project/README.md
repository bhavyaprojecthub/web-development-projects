# 🎂 Birthday Invitation Website
A simple HTML webpage that serves as an online birthday invitation.

## 📌 About
This project is a beginner-friendly HTML webpage that invites friends and family to a birthday celebration. It includes:
* Birthday announcement
* Birthday cake image
* List of things guests can bring
* Google Maps location link to the venue

## 🎉 Event Details
**Date:** 24th February

### What to Bring
* 🍕 An appetite (there will be lots of food!)
* 🧸 Plushies
* 🍫 Chocolates

### Venue
The invitation includes a Google Maps link directing guests to the celebration location.
