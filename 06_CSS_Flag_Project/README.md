# CSS Flag
A simple CSS project that recreates the national flag of Laos using only HTML and CSS.

### About
This project demonstrates the use of CSS positioning, selectors, colors, and shapes to accurately reproduce the Flag of Laos without using any images.

### Features
Built entirely with HTML and CSS
Uses CSS positioning and layout techniques
Creates the circular emblem using border-radius
No external libraries or frameworks


### Technologies Used
HTML5
CSS3

###  How to Run
Clone the repository.
Open the project folder.
Open index.html in your browser.
