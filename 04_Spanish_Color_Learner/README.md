# 🎨 Spanish Color Learner
A beginner-friendly web project built using HTML and CSS to help users learn color names in Spanish through text and visual representations.

## 📌 About
This project is designed to teach basic Spanish color vocabulary by displaying color names alongside corresponding images.
The website currently features:

* 🔴 Rojo (Red)
* 🔵 Azul (Blue)
* 🟠 Anaranjado (Orange)
* 🟢 Verde (Green)
* 🟡 Amarillo (Yellow)

## 🛠️ Technologies Used
* HTML5
* CSS3

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore and learn Spanish color vocabulary.
